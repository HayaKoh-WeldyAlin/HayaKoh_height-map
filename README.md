# HayaKoh_height-map
カスタムハイトマップジェネレーター by HayaKoh
作成者：林田光惺（HayaKoh）

## 概要
シードに基づいてハイトマップを自動で作成するツールです。
[Simutrans](https://www.simutrans.com/ja/)のハイトマップ作成用のツールとして作成しました。
[WebSim](https://websim.com/)を用いて作成し、いくつかの箇所を手動で編集しました。

## 仕様
いくつかの項目が設定できます。
### シード値
入力した文字列に応じて地図が変化します。
同じシードを入力すると毎回必ず同じマップが出現します。

### ランダム生成
ランダムなシードを抽選してハイトマップを作成します。

### ダウンロード
生成したファイルをダウンロードします。
ファイル名は`HayaKoh-height_{シード値}`です。
なお、シードに英数字以外の文字を使用した場合、ファイル名においては「_」に置き換えられてしまうようです。

### 横幅・縦幅
画像サイズをピクセル単位で編集します。
8～4096で指定できますが、縦幅が2のべき乗でなければ正常に生成できない場合があります。

### 最低高度・最高高度
-11～33（simutrans内座標と同じ）で指定します。
標高差を調整できます。
個人的に最低-5～最高10の設定がなだらかで好みです。

### 海面チェッカー
-11～33（simutrans内座標と同じ）で指定します。
海面高度を調べる場合に役立ちます。

simutransでの高さ座標とRGB値の対照（`レガシー`でのインポートの場合）は以下の通りのようです。
（6ずつの等差数列）
- -1 …
- 0	64
- 1	70
- 2	76
- 3	82
- 4	88
- 5	94
- 6	100
- 7	106
- 8 …
